# 似然函数（Likelihood Function）详解

## 1. 什么是似然函数？

似然函数是统计学中一个核心概念，它表示**在给定参数下，观察到当前数据的概率**。

### 数学定义

对于参数 \(\theta\) 和观测数据 \(x\)：
- **概率函数**：\(P(x|\theta)\) - 参数固定，数据变化
- **似然函数**：\(L(\theta|x)\) - 数据固定，参数变化

虽然数值上相等 \(L(\theta|x) = P(x|\theta)\)，但意义完全不同。

---

## 2. 似然 vs 概率：关键区别

| 维度 | 概率 (Probability) | 似然 (Likelihood) |
|------|-------------------|-------------------|
| **焦点** | 已知参数，预测数据 | 已知数据，推断参数 |
| **变量** | 数据是变量 | 参数是变量 |
| **总和/积分** | 对所有数据求和 = 1 | 对参数积分 ≠ 1 |
| **问题** | "给定硬币均匀，掷10次得到7次正面的概率？" | "掷10次得到7次正面，硬币均匀的可能性？" |

---

## 3. 直观例子：抛硬币

假设抛硬币10次，得到7次正面。我们想估计正面概率 \(p\)。

### 似然函数（二项分布）

\[L(p) = P(\text{7次正面}|p) = \binom{10}{7} p^7 (1-p)^3\]

### 不同 p 值的似然

| p 值 | 似然值 | 解释 |
|------|--------|------|
| 0.3 | 0.009 | 极不可能 |
| 0.5 | 0.117 | 不太可能 |
| 0.7 | **0.267** | **最大似然** |
| 0.9 | 0.057 | 较不可能 |

**结论**：p=0.7 时似然最大，这就是最大似然估计（MLE）。

---

## 4. 数学形式

### 离散分布
\[L(\theta|x) = P(X=x|\theta)\]

### 连续分布
对于密度函数 \(f(x|\theta)\) 和独立观测 \(x_1, x_2, ..., x_n\)：
\[L(\theta|x_1,...,x_n) = \prod_{i=1}^n f(x_i|\theta)\]

---

## 5. 对数似然函数（Log-Likelihood）

由于乘积容易下溢，通常取对数：

\[\ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log f(x_i|\theta)\]

**优势**：
- 将乘积转为求和，计算稳定
- 不改变极值点位置
- 简化求导运算

### 抛硬币例子的对数似然

\[\ell(p) = \log\binom{10}{7} + 7\log(p) + 3\log(1-p)\]

---

## 6. 最大似然估计（MLE）

寻找使似然函数最大的参数值：
\[\hat{\theta}_{MLE} = \arg\max_\theta L(\theta|x)\]

### 求解步骤
1. 写出似然函数 \(L(\theta)\)
2. 取对数得 \(\ell(\theta)\)
3. 对参数求导 \(\frac{d\ell}{d\theta} = 0\)
4. 解出参数 \(\hat{\theta}\)

---

## 7. 实战：正态分布的 MLE

给定数据 \(x_1,...,x_n\)，假设来自正态分布 \(N(\mu, \sigma^2)\)：

### 似然函数
\[L(\mu,\sigma^2) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x_i-\mu)^2}{2\sigma^2}\right)\]

### 对数似然
\[\ell(\mu,\sigma^2) = -\frac{n}{2}\log(2\pi) - \frac{n}{2}\log(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i-\mu)^2\]

### MLE 解
- \(\hat{\mu} = \frac{1}{n}\sum_{i=1}^n x_i\) （样本均值）
- \(\hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^n (x_i-\hat{\mu})^2\) （样本方差）

---

## 8. Python 实现示例

```python
import numpy as np
from scipy.stats import norm
import matplotlib.pyplot as plt

# 生成数据
np.random.seed(42)
data = np.random.normal(loc=5, scale=2, size=100)

# 定义似然函数
def likelihood(mu, sigma, data):
    return np.prod(norm.pdf(data, loc=mu, scale=sigma))

# 定义对数似然函数（更稳定）
def log_likelihood(mu, sigma, data):
    return np.sum(norm.logpdf(data, loc=mu, scale=sigma))

# 网格搜索 MLE
mus = np.linspace(4, 6, 100)
sigmas = np.linspace(1.5, 2.5, 100)
best_mu, best_sigma = None, None
max_ll = -np.inf

for mu in mus:
    for sigma in sigmas:
        ll = log_likelihood(mu, sigma, data)
        if ll > max_ll:
            max_ll = ll
            best_mu, best_sigma = mu, sigma

print(f"MLE 估计: μ = {best_mu:.3f}, σ = {best_sigma:.3f}")
print(f"真实值: μ = {np.mean(data):.3f}, σ = {np.std(data):.3f}")
```

## 9. 似然函数的性质

### 优点
- ✅ 理论基础扎实
- ✅ 在大样本下具有一致性、渐近正态性
- ✅ 广泛应用于各种统计模型

### 局限性
- ⚠️ 小样本可能偏差
- ⚠️ 对异常值敏感
- ⚠️ 复杂模型可能难以优化

---

## 10. 应用场景

1. **机器学习**：逻辑回归、神经网络损失函数
2. **生物统计**：遗传学参数估计
3. **金融**：波动率建模
4. **信号处理**：参数检测与估计
5. **A/B 测试**：转化率比较

---

## 11. 高级概念延伸

- **似然比检验**：比较嵌套模型的拟合优度
- **贝叶斯视角**：似然 × 先验 = 后验
- **EM 算法**：处理隐变量的似然优化
- **Fisher 信息**：似然函数曲率，衡量参数估计精度

---

## 12. 关键要点总结

🔑 **似然函数不是概率分布**，不必积分或求和为1  
🔑 **数据是固定的，参数是变量**  
🔑 **MLE 是最常用的参数估计方法之一**  
🔑 **对数似然简化计算且更稳定**  
🔑 **似然是现代统计和机器学习的基石**
